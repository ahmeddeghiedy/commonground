# Security policy

## Reporting a vulnerability

Please do not disclose security issues in a public GitHub issue. Use the repository's **Security → Report a vulnerability** flow to submit a private security advisory to the maintainers.

Include the affected route or WebMCP tool, reproduction steps, expected impact, and any suggested mitigation. Do not include real supplier credentials, invitation tokens, payment information, or traveler personal data.

## Scope

Security reports are especially valuable for authorization boundaries, invitation-token handling, workspace isolation, WebMCP argument validation, supplier-data normalization, and any behavior that could bypass the visible human-confirmation boundary.
